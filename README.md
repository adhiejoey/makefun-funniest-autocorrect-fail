A single-line autocorrect fail: a proud parent's reminder about the kids'
piano recital, ruined by one dropped letter that turns a school music night
into something no parent ever meant to announce.

## How it works

`main.ts` (Node 22, standard library only, no network) writes the one-line
entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
